## Files

### `RequestProject/EmergentMetric.lean` — Correlation Kernel and Emergent Distance

Defines a `CorrKernel` structure on a finite type `S` with a symmetric correlation function `I : S → S → ℝ` satisfying `0 < I i j ≤ 1` and `I i i = 1`. Defines the emergent distance `d i j = -log(I i j)` and proves:

- **`d_nonneg`**: `d i j ≥ 0`
- **`d_self`**: `d i i = 0`
- **`d_symm`**: `d i j = d j i`
- **`d_triangle`**: If `I i k ≥ I i j * I j k` (multiplicative triangle inequality), then `d i k ≤ d i j + d j k`
- **`d_pseudometric`**: Packages all pseudometric axioms together
- **`d_eq_zero_iff`**: If `I i j = 1 ↔ i = j` (separating), then `d i j = 0 ↔ i = j` — upgrading to a metric
- **`coupling_eq_I`**: The coupling `H i j = exp(-d i j)` equals `I i j`
- **`coupling_pos`** / **`coupling_le_one`**: Coupling is in `(0, 1]`
- **`coupling_anti`**: Interaction strength decreases as emergent distance increases
- **`recovery`**: If `I i j = exp(-‖x_i - x_j‖)` for some Euclidean embedding, then `d` recovers `‖x_i - x_j‖` exactly

### `RequestProject/Interference.lean` — Wave Amplitude and Interference

Defines `WaveAmplitude S = S → ℂ`, intensity `‖ψ(i)‖²`, and the cross term `2 Re(ψ₁(i) · conj(ψ₂(i)))`. Proves:

- **`interference_formula`**: `|ψ₁ + ψ₂|² = |ψ₁|² + |ψ₂|² + 2 Re(ψ₁ · conj ψ₂)` — the interference cross-term identity
- **`interference_relational`**: The formula holds for any type `S` with no geometric hypotheses — interference is purely relational

### `RequestProject/ToyModel.lean` — Seven-Node Double-Slit Model

Defines a concrete `Node` inductive type with 7 constructors (source, slitA, slitB, screen1–4) and two route amplitudes. Proves:

- **`cross_term_screen1_nonzero`**: The cross term at screen1 is nonzero — genuine interference
- **`interference_at_screen1`**: With both slits open, intensity ≠ sum of individual intensities
- **`screen_interference`**: The full interference formula applied to the model
- **`single_route_no_cross`**: Blocking one slit (setting its amplitude to zero) eliminates the cross term
- **`model_is_relational`**: The interference physics is invariant under arbitrary relabeling of the node set — no background space is assumed

## What this demonstrates

This is a theorem-level demonstration that: a wave can be fundamental, space need not be fundamental, and geometry can be induced from information/correlation structure while still reproducing interference-like physics. All definitions and theorems depend only on the finite type `S` and the correlation kernel `I` — no embedding into ℝⁿ, no manifold, and no metric space structure is presupposed.
